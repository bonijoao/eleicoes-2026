# Eleições 2026: auditoria aberta dos logs das urnas

Este repositório testa, com os arquivos públicos do TSE (logs e boletins de cada urna),
alegações concretas de fraude feitas sobre o 2º turno de 2026. Não afirmamos ausência de
fraude: dizemos qual marca cada alegação deixaria nos dados, medimos e publicamos o código
para qualquer pessoa refazer a conta.
